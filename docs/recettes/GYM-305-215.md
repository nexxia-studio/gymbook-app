# Recette — GYM-305 (logo) + GYM-215 (images d'activités)

⚠️ **Aucune migration, aucun déploiement.** La fondation Storage est déjà posée en staging
par le cockpit (bucket `gym-media`, policies). Le lot est **dashboard uniquement** : rien
n'a été touché côté mobile, qui consomme déjà `logo_url` et `image_url`.

Compte de test : le **gym_admin de Studio Yoga Test 1**. Prépare deux fichiers — un PNG
d'environ 500 × 100 (logo) et un JPEG paysage (image de cours) — plus **un fichier > 2 Mo**
et **un PDF**, qui servent aux refus.

## 1. Le logo (GYM-305)

| # | geste | attendu |
|---|---|---|
| S1 | Réglages → Apparence | le champ « Lien vers ton logo » a disparu ; à sa place une **zone de dépôt**, vide, qui annonce les formats et « 2 Mo maximum » |
| S2 | 🔴 **Glisser** le PNG dans la zone | bordure qui réagit au survol, roue pendant l'envoi, puis **l'aperçu dans un cadre 5:1 sur fond sombre** |
| S3 | S2 → un toast | « Modifications enregistrées ». **Sans avoir cliqué sur « Enregistrer »** — c'est voulu, voir le commentaire de `persisterLogo` |
| S4 | Recharger la page | le logo est toujours là (il vient de la base, pas de l'écran) |
| S5 | **Cliquer** la zone au lieu de glisser | le sélecteur de fichiers s'ouvre ; même résultat |
| S6 | 🔴 Déposer un **second** PNG différent | l'aperçu change **immédiatement**. Pas d'ancien logo qui persiste — c'est ce que teste `?v=` |
| S7 | 🔴 Déposer un **JPEG** par-dessus le PNG | l'aperçu change. Dans le bucket, `logo.png` a **disparu** : un seul objet par salle |
| S8 | Déposer le fichier **> 2 Mo** | refus **sans requête réseau** : « Image trop lourde (x,x Mo). Maximum 2 Mo. » |
| S9 | Déposer le **PDF** | refus : « Format non accepté. Formats possibles : PNG · JPEG · WEBP · SVG. » |
| S10 | Après S8 ou S9, redéposer **le même fichier** valide | l'envoi part (le champ est remis à zéro — sinon le second geste serait muet) |
| S11 | « Retirer l'image » | la zone redevient vide, la base repasse à `null`, l'objet est supprimé du bucket |
| S12 | 🔴 Modifier **couleurs / nom court** puis « Enregistrer » | le logo **n'est pas écrasé** — il ne fait plus partie de cette écriture |
