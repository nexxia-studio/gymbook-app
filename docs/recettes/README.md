# Recettes par lot

**Un lot = un fichier.** Écris la recette de ton lot dans `docs/recettes/<ticket>.md`, jamais
dans `docs/GYM-292-audit-salle-active.md` — trois lots qui ajoutent une section au même
document conflictent deux à deux à chaque merge, pour des blocs pourtant indépendants.

Nomme le fichier d'après le ou les tickets qu'il couvre (`GYM-294.md`,
`GYM-306-308.md`), et donne à chaque étape un identifiant stable pour qu'on puisse la citer
en revue.
